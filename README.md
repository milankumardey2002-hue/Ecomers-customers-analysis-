# E-Commerce Customer Analytics (Sec D)

A web-only project (HTML + CSS + JavaScript). No installation, server or internet needed.

## How to run
Unzip and double-click `index.html` (any modern browser).

## Files
- `index.html` – page structure (5 tabs)
- `style.css` – styling
- `js/core.js` – data generation, preprocessing, Linear/Logistic Regression, KNN, K-Means, cross-validation (written from scratch)
- `js/ui.js` – charts and interface

## Project steps covered
1. Collect data (simulated customers, products, purchases, browsing, ratings)
2. Preprocess (duplicates, missing values, outliers, encoding, scaling)
3. Analyze (sales trends, popular products, behaviour charts)
4. Models: Linear Regression (spending), Logistic Regression (purchase yes/no), KNN (product recommendation), K-Means (Premium / Regular / Occasional)
5. Optimize with 5-fold cross-validation
6. Display results: predicted spending, purchase probability, segment, recommendations
